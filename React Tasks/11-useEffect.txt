//!Activity 1: Predict the Output 🎯
-->You are developing a shopping application. Whenever the user changes the selected product quantity, you want to display a message in the console.
import { useState, useEffect } from "react";
function ShoppingCart() {
    const [quantity, setQuantity] = useState(1);
    useEffect(() => {
        console.log("Quantity Updated");
    }, [quantity]);
    return (
        <>
            <h2>Quantity: {quantity}</h2>
            <button onClick={() => setQuantity(quantity + 1)}>
                Add Item
            </button>
        </>
    );
}
export default ShoppingCart;

Questions:
Q1. What will be displayed in the console when the component renders for the first time?
Q2. The user clicks the Add Item button once. What will be displayed in the console?
Q3. The user clicks the button three times. How many times will "Quantity Updated" be logged in total, including the initial render?
Q4. What happens if you change the dependency array from [quantity] to []?
Q5. Why do we use [quantity] in this example?


//!Activity 2: Debug the Mistake 🐛
-->You are developing a student dashboard that displays a student's name.
Whenever the student's name changes, the application should display the updated name in the console.

import { useState, useEffect } from "react";
function StudentDashboard() {
    const [name, setName] = useState("Rahul");
    useEffect(() => {
        console.log("Student Name:", name);
    }, []);
    return (
        <>
            <h2>Student: {name}</h2>
            <button onClick={() => setName("Arjun")}>
                Change Student
            </button>
        </>
    );
}
export default StudentDashboard;

//!The Problem
When the component initially renders, the console displays:
Student Name: Rahul
When the user clicks Change Student, the heading updates to Arjun, but the console does not display the updated name.

Questions:
Q1. Identify the mistake in the code.
Q2. Correct the code so that the effect executes after the initial render and whenever the student's name changes.
Q3. Predict the console output after the following actions:
1. Open the application.
2. Click Change Student once.
3. Click Change Student again.
Q4. Why is an empty dependency array incorrect for this requirement?
