//!Activity 1: Predict the Output
-->Read the code and predict what happens when the button is clicked.

const PriceChecker = () => {
  const showPrice = (price) => {
    console.log(`Product price: ₹${price}`);
  };
  return (
    <button onClick={() => showPrice(1499)}>
      Check Price
    </button>
  );
};

export default PriceChecker;

Questions:
1. What appears in the console when the button is clicked?
2. Will showPrice() execute automatically when the component renders?
3. Why is an arrow function used inside onClick?
